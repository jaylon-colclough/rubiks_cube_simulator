This is a simple rubik's cube simulator coded in Java. This is my first solo coding project. I also finished creating an interactive window and gui to display and manipulate the cube. Importantly, in the code when referencing a mover object, the numbers -1 and 1 refer to the direction of the move/turn. For example, a rubiks cube can turn a layer clockwise or counter clockwise. To replicate this, -1 was used to represent the counter clockwise rotation and 1, clockwise.
